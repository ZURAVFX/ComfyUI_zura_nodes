# Zura OpenAI Image API

Add **Zura · ChatGPT Image (API Key)** from **Zura / Image** in the ComfyUI graph. Choose **OpenAI API key** and paste your existing OpenAI project key into the masked field. It stays in memory for this ComfyUI process and is shared by instances of this node. Clear it from the same dialog or restart ComfyUI. The dialog is available when ComfyUI is listening locally only. For a headless or remote installation, set `OPENAI_API_KEY` in the environment that starts ComfyUI. A session key takes precedence over the environment key. Workflows contain neither key.

Each enabled node runs when queued and uses the selected OpenAI project's API credits. **Auto** generates from text or edits when you supply a reference. Connect images to **Reference 1** and **Reference 2**, then click **Add reference** for more individual sockets. The sockets also accept batches, with a total limit of sixteen images. Advanced settings also accept HTTPS URLs, data URLs and OpenAI file IDs. A white ComfyUI mask marks the area to edit in the first reference. For annotation-guided edits, connect a transparent RGBA overlay or connect both outputs of **Load Image** to **Markup overlay** and **Markup alpha**.

To create all three guides on one frame, add **Zura · Image Guidance Painter**. Connect a frame and click **Draw guidance**. Images from **Load Image** appear immediately. For other nodes, click **Fetch connected frame** to run just the upstream image path. Paint the edit area, draw coloured markup with brushes, arrows or boxes, and use **Markup alpha** to hide or restore the marks. **Use drawing** saves the strokes in the workflow. The painter passes its first frame through **reference** so that the guide and the first ChatGPT reference use the same pixels and dimensions.

For a masked edit, connect **edit mask**. For a markup-guided edit, connect **markup overlay**, which already carries its transparency. Connect **markup alpha** alongside the overlay if you also need the separate matte. OpenAI accepts one type of guidance per request, so use separate ChatGPT requests if you want to use both.

The **Model** picker includes the documented GPT Image models and snapshots. It adds any extra GPT Image models listed for the key after you connect. Choose **Custom** under **Output size** to set native dimensions. For supported still models, both edges must be multiples of 16, no greater than 3840, with an aspect ratio between 1:3 and 3:1 and 655,360 to 8,294,400 total pixels. For example, use `1536x864` for exact 16:9 or `3840x2160` for UHD. The node reports the actual raster size and raises an error if it differs from an explicit request.

The estimate above **Balance** shows expected image output charges in USD for the current size, quality and image count, including requested streamed partials. With automatic size it shows a 1024×1024 example, and with automatic quality it shows the range across supported quality levels. Text, references and SVG authoring are billed separately. GIFs and models without verified pricing only show the **Balance** link. Click it to open OpenAI's billing dashboard for the current organisation balance.

The optional input dimensions resize connected references locally before upload. Leave both values at zero to send the original pixels. The explicit dimensions stretch the image and its mask or overlay together. Set input dimensions upstream if you want to crop or fit instead.

Advanced settings cover render quality and planning complexity where supported, output backgrounds and compression, image count, streamed partial previews, GIF frame count and timing, SVG author options, and request identifiers. Availability can depend on the selected model and your OpenAI project. Streaming partials use additional image output tokens.

The node outputs an image and an inverse-alpha ComfyUI mask per result. Transparent results carry straight RGBA on **images**, so you can connect directly to **Save Image** to keep the alpha channel in the PNG. Opaque results use RGB. An animated GIF also returns its frames as an IMAGE batch. The API receipt reports the model, sizes, saved paths, request ID and any usage information returned by OpenAI. The node can save the original bytes to `ComfyUI/output/zura_openai`. GIF and SVG are always saved in their original formats. For SVG, use the **original file** output or retrieve the file from that folder.
