Zura Nodes · Video tools for ComfyUI

Transform footage. Keep control of the shot.

Zura Studio brings video-to-video work into ComfyUI. Carry motion into a new look, replace characters, or take a grey viewport render towards a finished scene.

  • 01Character performanceUse Wan, H3 or LTX to follow a source performance with a new character. Choose original audio, uploaded replacement dialogue or silent footage.
  • 02Head & faceH3 uses a portrait and the original facial performance, then blends a tracked face crop back into the source. Original audio, up to two seconds.
  • 03Viewport to finalTurn a grey 3D blockout into a finished scene. MiniMax H3 is the tested local starting point for this mode.
  • 04Editable graphsSwitch from Studio to native nodes with your loaded media. Keep prompts, clip controls and generated results available for inspection.

A short path from source to render.

  1. Add a video and choose a mode

    See the source preview, then choose Character performance or Viewport to final.

  2. Set the look and review the guidance

    Use a finished frame or add look references and a prompt. Check the mask or depth guidance before you build.

  3. Choose a local model and render

    Set the clip length and resolution for that model, then compare the result with your source and adjust the graph if needed.

Install the tool. Choose your model.

Zura Studio is included in the Zura Nodes ComfyUI pack. The pack and video model weights are separate downloads.

  1. Install Zura Nodes

    In ComfyUI Manager, search for “Zura Nodes” and install the listing published by ZURAVFX. If the listing is awaiting review, use the source ZIP on the official GitHub Releases page. The install guide explains folder placement and Python requirements.

  2. Restart ComfyUI

    After installing, restart ComfyUI and open Zura Studio from its sidebar. The install guide has the manual steps and requirements.

  3. Set up one model first

    Choose an engine in Studio and follow the model setup guide. Weights are downloaded separately; some are large or have their own access terms.
